# ✅ ComicCraft — Demo Checklist
### AI Comic Story Creator | College / Project Demonstration Guide

---

## 🖥️ BEFORE THE DEMO — Pre-flight Setup (Do This First)

- [ ] Virtual environment is created and dependencies are installed
- [ ] `.env` file exists with a valid `GEMINI_API_KEY`
- [ ] Internet connection is active (required for Gemini API)
- [ ] Browser is open (Chrome or Edge recommended)
- [ ] Terminal / PowerShell is open in the `ComicCraft/` directory

---

## STEP 1 — Start the Backend

Open a terminal inside the `ComicCraft/` folder and run:

```powershell
# Activate virtual environment (Windows)
..\.venv\Scripts\activate

# Start the FastAPI server
uvicorn app.main:app --reload
```

**Expected output:**
```
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Started reloader process
INFO:     Application startup complete.
```

> ✅ The server is ready when you see **"Application startup complete."**

---

## STEP 2 — Open the Application

In the browser, navigate to:

```
http://127.0.0.1:8000
```

**What the panel shows:**
- ComicCraft home page with the story input form
- Fields: Story Prompt, Character Name, Setting, Tone, Art Style
- A **"Generate Comic"** submit button

**Expected response:**

{ "status": "ok", "service": "ComicCraft" }

## STEP 4 — Enter the Demo Story Prompt

Use the following **recommended demo inputs** (tested, family-friendly, visually rich):

| Field | Value |
|---|---|
| **Story Prompt** | `A young inventor named Aria builds a small robot friend in her attic workshop. Together they go on an adventure through the city, solve a mystery, and become the talk of the neighbourhood.` |
| **Character Name** | `Aria` |
| **Setting** | `Futuristic city with a cosy attic workshop` |
| **Tone** | `Adventurous and heartwarming` |
| **Art Style** | `Comic book with bold lines and vibrant colours` |

> 💡 **Why this prompt works well for a demo:**
> - Clear main character with a name Gemini can keep consistent
> - Rich visual setting gives Hugging Face / fallback images good contrast
> - Adventurous tone produces exciting panel-to-panel narrative
> - Comic book art style is the most recognisable

## STEP 5 — Submit and Wait

Click **"Generate Comic"**.

**During generation, explain to audience:**
> *"The app is now making two calls to Google Gemini — first to generate a five-panel story outline, then to expand each panel into a full comic script with captions, narration, and dialogue. After that it generates one image per panel using Hugging Face inference."*

**Expected wait time:**
- Gemini outline + story: ~5–15 seconds
- Image generation (5 panels): ~30–90 seconds (depends on HF load)
- Total: typically **45–120 seconds**

A loading spinner is displayed on the page during generation.

## STEP 10 — Gemini Error Recovery (If It Happens)

**If Gemini returns a 429 (quota) or 503 (overloaded) error during the demo:**

> *"Gemini occasionally returns rate-limit or overload errors during peak usage. The application handles this automatically — it retries the request using a fallback chain of Gemini models: gemini-flash-lite-latest → gemini-3.8-flash → gemini-3.5-flash. This means the user never sees a raw API error; they see a friendly message and the system retries silently."*

**What the code does:**
- `gemini_client.py` catches `APIError`, `ServerError`, and `ClientError`
- Tries up to 5 different Gemini model endpoints in sequence
- Only raises a user-visible error if all models are exhausted

**Recovery:** Simply click the browser back button and click **"Generate Comic"** again.

---

## STEP 11 — Hugging Face Fallback (If Images Are Placeholders)

**If panel images show the branded placeholder instead of AI-generated art:**

> *"Hugging Face hosted inference has rate limits on the free tier, and image generation can occasionally fail. The application is designed to be resilient — if image generation fails for any reason, it automatically creates a styled comic panel placeholder using Python's Pillow library. The story narration, captions, dialogue, and PDF export all still work perfectly. The application never crashes just because image generation is unavailable."*

**Point out on the placeholder image:**
- "PANEL N" badge in red — maintains panel numbering
- Prompt summary text — shows what the image would have contained
- Note at the bottom — explains why the placeholder was used
- Comic-styled dark frame — maintains the visual comic aesthetic

> 💡 *This is a feature, not a bug — it demonstrates graceful degradation, a key principle in production AI systems.*
